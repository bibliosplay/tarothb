Creador de Prompts

Crea 22 cartas de tarot con conceptos nuevos a partir de cada pintor: elegí un artista (o dejá que te sugiera uno), y el generador inventa para cada Arcano un nombre, una escena y unas claves propias, listos para copiar en Midjourney, DALL·E o Stable Diffusion.

No se pudo cargar cards.json. Si abriste este archivo con doble clic, algunos navegadores bloquean la lectura local: usá un servidor local (python -m http.server) o "Live Server".

1 · Elegí un pintor o estilo

Cada pintor tiene su propio mundo: los conceptos, nombres y escenas de las 22 cartas cambian para encajar en él. Podés elegir uno del menú, escribir el tuyo o dejarte sugerir.

Tu estilo define la técnica y la paleta; los conceptos usan una plantilla genérica ya que no conocemos el mundo de ese artista. Podés editar cada prompt después.

2 · Generar las 22 cartas

Cada carta queda limpia: el número y el nombre del Arcano arriba, el nombre generado abajo. La explicación completa con escena, conceptos y estilo se vuelca al Cuaderno.

3 · Cuaderno: la intención de cada carta

Aquí está la explicación e intención básica de cada carta: el texto completo con escena, conceptos, claves y estilo, listo para copiar en tu generador de imágenes (Midjourney, DALL·E o Stable Diffusion).

Creador de Prompts — complemento del Tarot del Jardín de las Delicias. Las imágenes generadas a partir de estos prompts son originales; no reproducen obras existentes.
